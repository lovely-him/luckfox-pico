## 功能概述

这是启动过程的**第一阶段**，由 **DDR 初始化二进制文件**（DDR init blob）执行。此阶段在任何 CPU 代码之前运行，负责：

1. **内存控制器配置** - 设置 DDR3 内存控制器
2. **时序参数配置** - 配置 DDR3 时序参数
3. **内存训练** - 运行内存校准和训练序列
4. **内存测试** - 验证内存完整性

## 代码位置

### 二进制文件
- **路径**: `/sysdrv/source/uboot/rkbin/bin/rv11/rv1106_ddr_924MHz_v1.15.bin`
- **类型**: 预编译二进制文件（无源代码）
- **版本**: v1.15（由 wesley.yao 于 2023/12/21 构建）

### 配置文件
- **路径**: `/sysdrv/source/uboot/rkbin/RKBOOT/RV1106MINIALL.ini`
- **章节**: `[CODE471_OPTION]`
- **参数**: `NUM=1` 和 `Path1=bin/rv11/rv1106_ddr_924MHz_v1.15.bin`

### 集成点
DDR 初始化二进制文件由 **BootROM**（硬编码在 RV1106 芯片中）加载，并在 U-Boot SPL 之前从 SRAM 执行。

## 关键参数分析

### 第 1 行：版本信息
```
DDR 306b9977f5 wesley.yao 23/12/21-09:28:37,fwver: v1.15
```
- **构建 ID**: `306b9977f5`（Git 提交哈希或构建标识符）
- **作者**: wesley.yao（Rockchip 工程师）
- **构建日期**: 2023 年 12 月 21 日 09:28:37
- **固件版本**: v1.15

### 第 2-6 行：内部调试输出
```
S5P1
4x
f967
rgef1
DDRConf2
```
这些是 DDR 初始化代码的内部调试标记：
- **S5P1**: 可能表示"阶段 5 相位 1"或类似的内部检查点
- **4x**: 内存配置模式（可能是 4x 模式）
- **f967, rgef1**: 内部寄存器值或检查点
- **DDRConf2**: DDR 配置配置文件 #2

### 第 7 行：内存配置
```
DDR3, BW=16 Col=10 Bk=8 CS0 Row=14 CS=1 Size=256MB
```

详细分解：
- **DDR3**: 内存类型（DDR3 SDRAM）
- **BW=16**: 总线宽度为 16 位（每次传输 2 字节）
- **Col=10**: 10 位列地址（1024 列）
- **Bk=8**: 每个芯片 8 个 bank
- **CS0 Row=14**: 片选 0 有 14 位行地址（16384 行）
- **CS=1**: 仅 1 个片选激活（单 rank 内存）
- **Size=256MB**: 总内存大小

**内存计算验证**:
```
大小 = 2^(Col) × 2^(Row) × Banks × BW × CS
     = 2^10 × 2^14 × 8 × 2 × 1
     = 1024 × 16384 × 8 × 2
     = 268,435,456 字节
     = 256 MB ✓
```

### 第 8 行：工作频率
```
924MHz
```
- **DDR 时钟**: 924 MHz
- **数据速率**: 1848 MT/s（DDR = 双倍数据速率）
- **带宽**: 1848 MT/s × 16 位 = 29,568 Mb/s = 3.696 GB/s 理论值

### 第 9 行：完成标记
```
DDR bin out
```
表示 DDR 初始化成功完成并移交给下一个启动阶段。

### 内存带宽
- **理论峰值**: 3.696 GB/s
- **实际带宽**: 约 2.5-3.0 GB/s（考虑协议开销）

### 延迟
- **CAS 延迟**: 日志中未显示（DDR3-1866 通常为 CL=6 或 CL=7）
- **tRCD, tRP, tRAS**: 未显示（由 DDR init 二进制文件内部配置）

## 优化考虑

### 频率调整
可以通过使用不同的二进制文件来更改 DDR 频率：
- **可用二进制文件**: 检查 `/sysdrv/source/uboot/rkbin/bin/rv11/` 以获取其他频率选项
- **常见选项**: 528MHz、664MHz、784MHz、924MHz、1056MHz

### 内存大小
内存大小**取决于硬件**，无法通过软件更改。Luckfox Pico Ultra W 板载焊接了 256MB。
